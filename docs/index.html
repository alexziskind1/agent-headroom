memory-aware benchmarks for agent fleets

How many agents can your box run before it clips?

Headroom is the margin before clipping. Agent Headroom replays real coding-agent sessions against your own hardware and measures five kinds of margin: size, speed, concurrency, models, and context.

one session drives the fleet

Probe, plan, run, report. Nothing to install on the targets beyond Python and a server.

The probe reads memory from the driver, never from comparing sizes. The planner only schedules what fits. The runner refuses anything the box changed since the plan.

bench probe

Read the machine

Topology, device and host memory, bandwidth, storage. Unified, discrete, coherent, or a cluster of nodes.

bench plan

Size the test

Picks the model, quant, context and placement from the catalog that fit this box, and says why anything was rejected.

bench run

Replay the agents

Launches the server with pinned flags, replays the recorded sessions, samples memory the whole time.

bench report

Fold the fleet

One table per test across every machine, including runs fetched back from remote hosts and clusters.

# on the box you are sitting at
python3 -m bench probe
python3 -m bench plan inference --model qwen3.8-27b --context 65536
python3 -m bench run out/plan-<host>-inference.json --replay agentperf-default-v1

# the same test on another machine in the fleet, results come back to out/remote/
python3 -m bench remote <host> probe
python3 -m bench remote <host> run out/plan-<host>-host_pressure.json --levels 1,2,4,8,16

# fold everything into one report
python3 -m bench report   # markdown tables per test

badges

Three things most benchmarks skip.

BRIDGE

Coherent memory. On a DGX Station the GPU reads weights out of LPDDR over NVLink-C2C; the ladder measures how much of a 433 GiB model can live there and what it costs.

FLEET

Clusters. Several machines become one probe, one plan and one run, with the link between them measured, and a model split across nodes when none holds it alone.

TRACKS

Engine rows. llama.cpp on every machine for a fair comparison, plus vLLM, MLX or TensorFold where they are the fastest thing people actually run.

rules of the suite

Honest by construction.

Frozen workload

Recorded sessions from AgentPerf, replayed exactly. The same 2.5 million prompt tokens on every box, with the never-cacheable share fixed.

Memory from the driver

Topology comes from CUDA attributes, Metal, or sysfs, never from guessing by size. A 96 GB card next to 92 GB of RAM is still discrete.

Pinned artifacts

Every model file has a byte count and a SHA-256 in the catalog. A run on the wrong file says so in the result.

Failures are results

A dropped turn, an eviction that did not round-trip, a server that would not load: all recorded with the memory trace, not retried away.
